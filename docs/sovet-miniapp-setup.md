# Mini App «Попечительский совет» — отдельный бот (настройка в BotFather)

Памятка для **владельца ботов**. Нужна, чтобы ярлык на главном экране телефона
у членов Совета:
- назывался **«Попечительский совет»**, и
- открывал раздел **/sovet**, а не приложение жителей.

## Почему нужен ОТДЕЛЬНЫЙ бот
Telegram при «Добавить на главный экран» создаёт ярлык **на бот**: берёт его
**имя** и его **главный Mini App**. У общего бота @SkazKray_bot имя «Сказочный
Край», а главный Mini App — приложение жителей `/app`. Поэтому через него ярлык
всегда будет «Сказочный Край» и будет открывать `/app`. Ни название Mini App
`sovet`, ни код сайта это не меняют. Единственное решение — **свой бот Совета**,
у которого имя = «Попечительский совет», а главный Mini App ведёт на `/sovet/tg`.
Переименовывать общий бот нельзя — через него входят жители.

## Шаги в BotFather

### 1. Создать бота
1. @BotFather → **`/newbot`**.
2. **Name (имя):** `Попечительский совет` — это станет подписью иконки на главном экране.
3. **Username:** например `SkazKraySovet_bot` (должен заканчиваться на `_bot`).
4. BotFather выдаст **токен** — его нужно передать разработчику (он пропишет на сервере). Токен секретный, никому больше не показывать.

### 2. Сделать /sovet главным Mini App бота
Чтобы ярлык открывал именно раздел Совета:
1. @BotFather → **`/mybots`** → выбрать нового бота → **Bot Settings** → **Menu Button** → **Edit menu button URL**.
2. Ввести URL: **`https://skaz-kray.ru/sovet/tg`**
   (кнопка-меню = главный Mini App бота; именно его открывает ярлык с главного экрана).

### 3. (по желанию) Иконка и описание
- **Bot Settings → Edit Botpic** — загрузить картинку; она станет значком на главном экране.
- **`/setdescription`**, **`/setabouttext`** — тексты бота.

## Что делает разработчик (серверная часть)
- Код уже готов принимать вход Совета от отдельного бота: параметр
  `telegram.council_bot_token` (env `SOVET_BOT_TOKEN`). Как только пришлёте токен —
  он прописывается на сервере, и вход в `/sovet/tg` начинает проверяться этим ботом.
- Пока токен не задан — вход работает через общий бот жителей (ничего не ломается).

## Ссылка для членов Совета
После настройки — рассылать **ссылку на нового бота**:
```
https://t.me/<username_нового_бота>
```
(например `https://t.me/SkazKraySovet_bot`). Член открывает → вводит фамилию →
внутри жмёт «Добавить на главный экран» → значок **«Попечительский совет»**,
открывающий `/sovet`.

## Проверка
1. Открыть `https://t.me/<username_нового_бота>` на телефоне в Telegram.
2. Должен открыться экран «Вход в приложение → Введите Вашу фамилию».
3. Войти → «Добавить на главный экран» → ярлык называется «Попечительский совет»
   и открывает раздел Совета.

## Важно
- Приложение и вход **жителей** (@SkazKray_bot, `/app`) не затрагиваются.
- «Добавить на главный экран» надёжнее всего на **Android**; на **iPhone** возможности
  Telegram ограничены.
