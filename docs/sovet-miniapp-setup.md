# Mini App «Попечительский совет» — настройка в BotFather

Памятка для **владельца бота @SkazKray_bot**. Нужна, чтобы у членов Совета
иконка на главном экране называлась **«Попечительский совет Общего Дома»** и
открывала раздел `/sovet`, а не приложение жителей `/app`.

Имя иконки, её картинка и то, какое приложение она открывает, задаются **здесь,
в BotFather** — не в коде сайта. Серверная часть (`https://skaz-kray.ru/sovet/tg`)
уже готова и работает.

## Что понадобится
- Доступ к **@BotFather** от владельца бота @SkazKray_bot.
- Картинка-иконка для приложения (квадратная, например PNG; BotFather подскажет
  требуемый размер при загрузке).

## Шаги (создание отдельного Mini App)
1. Открыть в Telegram **@BotFather**.
2. Отправить команду **`/newapp`**.
3. В списке выбрать бота **@SkazKray_bot**.
4. **Title (название):** `Попечительский совет Общего Дома`
   — именно это станет подписью иконки на главном экране телефона.
5. **Description (описание):** например `Внутренний портал Попечительского совета: собрание, задачи, бюджет.`
6. **Картинка:** загрузить иконку по запросу BotFather (станет значком приложения).
7. **Web App URL:** `https://skaz-kray.ru/sovet/tg`
   — это гарантирует, что иконка ведёт в раздел Совета.
8. **Short name (короткое имя):** `sovet`
9. BotFather подтвердит создание. Ссылка приложения:
   **`https://t.me/SkazKray_bot/sovet`**

## Проверка (с телефона, в Telegram)
1. Открыть `https://t.me/SkazKray_bot/sovet`.
2. Должен появиться экран **«Вход в приложение → Введите Вашу фамилию»**.
3. Ввести фамилию из состава Совета → откроется раздел Совета.
4. Нажать кнопку **«Добавить на главный экран»** (или пункт «⋮ → Добавить на
   главный экран»). На главном экране появится значок **«Попечительский совет
   Общего Дома»**, открывающий сразу `/sovet`.

## Важно
- Это **отдельное** приложение (`sovet`). Приложение жителей (`app`) и вход
  жителей **не затрагиваются** — это разные Mini App одного бота.
- Члены Совета должны входить **только** по ссылке `https://t.me/SkazKray_bot/sovet`.
  Если заходить через приложение жителей, иконка на главном экране получит имя и
  цель приложения жителей — не то, что нужно.
- Кнопка «Добавить на главный экран» лучше всего работает на **Android**. На
  **iPhone** поддержка у Telegram ограничена; если пункта нет — обновить Telegram
  или пользоваться приложением из чата бота.

## Изменить позже
- `/myapps` или `/editapp` в BotFather → выбрать `sovet` → менять название, URL,
  иконку, описание.
